# [Kafka] 섹션 1 - 시작하며: 학습 환경 준비

데브원영의 [아파치 카프카 애플리케이션 프로그래밍] 강의를 정리하는 시리즈.

무료 강의였던 for beginners가 카프카의 지도를 그려줬다면, 이 강의는 그 지도 위를 실제로 걷는 과정임.

프로듀서·컨슈머의 내부 구조와 옵션, 멱등성과 트랜잭션, 스트림즈, 커넥트까지 오픈소스 아파치 카프카의 공식 기능 전체를 다룸.

## 준비물

| 도구 | 용도 |
|---|---|
| **iTerm2** (맥) / Windows Terminal + WSL (윈도우) | 브로커 실행, `kafka-*.sh` CLI 실습 |
| **IntelliJ Community Edition** | Java 애플리케이션 개발·빌드·실행 |
| **실습 소스코드** | github.com/bjpublic/apache-kafka-with-java |
| **강의자료 PDF** | 각 섹션 첫 수업에서 다운로드 |

강의는 맥 기준으로 진행되지만 JVM이 도는 환경이면 어디서든 실습 가능함.

윈도우에서는 쉘 스크립트 실행 때문에 WSL이 필요할 수 있음.

## 왜 자바인가

오픈소스 아파치 카프카가 공식 지원하는 라이브러리가 자바임.

프로듀서, 컨슈머, 스트림즈, 커넥트 모두 자바 라이브러리로 제공되고 카프카 본체와 릴리즈가 함께 관리됨.

Go나 JavaScript 등 다른 언어 라이브러리는 서드파티라서 모든 기능이 동일하게 제공된다는 보장이 없음.

특히 스트림즈와 커넥트는 자바 외의 선택지가 없음.

## 실습 최소 사양

- 메모리 8GB 이상, CPU i3(3GHz) 이상
- 주키퍼와 브로커를 로컬에 띄우므로 디스크 여유 공간 1GB 이상
